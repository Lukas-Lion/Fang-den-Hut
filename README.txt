FANG DEN HUT – GitHub Pages
===========================

Enthalten:
- index.html        -> direkt lauffähiges Spiel
- fang-den-hut.txt  -> identische Textkopie des Codes

GitHub Pages:
1. Inhalt dieses ZIP-Archivs entpacken.
2. index.html in das gewünschte GitHub-Repository hochladen.
3. Repository -> Settings -> Pages.
4. Deploy from a branch auswählen, Branch "main" und Ordner "/ (root)".
5. Speichern. Nach kurzer Zeit ist das Spiel über die GitHub-Pages-Adresse erreichbar.

Funktionen:
- 2 bis 6 Spieler
- Mensch oder Computergegner
- Responsive für Handy und PC
- Würfel, Zugprüfung, Richtungswahl über mögliche Zielfelder
- Hütchen fangen und Türme bilden
- Ruhefelder mit 3er-Limit
- Heimkehr mit Gefangenen, Befreiung eigener Hütchen
- Extra-Zug bei gewürfelter 6
- 3 Spielmodi: Standard, Wer übrig bleibt, Der Turm
- Spielstand automatisch im Browser gespeichert
- Fortsetzen, Zug zurück, Vollbild, Sound, Spielregeln
- Keine externen Bibliotheken oder Dateien notwendig

Hinweis:
Dies ist eine inoffizielle, eigenständige digitale Umsetzung der klassischen Spielidee.
